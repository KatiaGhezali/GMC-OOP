# Object Oriented Shopping Cart

A simple interactive shopping cart built with JavaScript using Object Oriented Programming (OOP).

## Features

- Create products with an ID, name, and price.
- Add products to the cart.
- Increase and decrease product quantities.
- Remove products from the cart.
- Display the total number of items.
- Calculate the total price.

## Classes

- `Product` stores product information.
- `ShoppingCartItem` stores a product and its quantity and calculates its total price.
- `ShoppingCart` manages the cart items and provides the cart functionalities.
